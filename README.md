所以实际的选择规则很清楚：主要给国内用户访问、能接受偶尔换 IP → 软银；要 IPv6、要省心、不想折腾 IP → IIJ。社区实测的结论也差不多——面向国内访问，IIJ 是放货多、风险低的选择。拿不定主意之前，可以先拿东京的公开测试 IP（IPv4 45.94.40.13）在自己网络环境里跑一下 ping 和路由，比看任何评测都直观。

## 便宜是有原因的：这些限制下单前要知道

低价套餐的坑，大多藏在条款和实测细节里，而不是价格表上。

**退款是最大的坑。** 特价套餐页明确标注 "No refund/Money back"，包括 Premium KVM Sale、Storage 大盘机和 CN Premium Optimized，付了就不退。常规套餐的退款政策也偏严：仅限首次购买的客户、7 天内申请，比特币支付一律不退款。所以不存在“买来试试再退”这条退路。

**宣传配置和实际到手可能有出入。** 有第三方实测过 GreenCloud 的存储机，宣传 4 核 EPYC，到手是 Xeon Platinum 8255C（软银节点）和 Xeon Skylake（IIJ 节点），GB5 单核跑分 782 和 729。第三方测评站对软银大盘机的简评也直言“超售情况比较明显”，但同时认为考虑到低价大盘机的定位，整体仍有吸引力。这类低价位超卖在行业里算常见操作，知道就好。

**10Gbps 是端口标称值，不是保证速率。** 官方页面自己也说明了这一点，实际速度受资源占用、拥堵和路由影响。2025 年的评测口径是东京节点电信下载能跑到 100Mbps+、电信/联通延迟 50–80ms；更早 2022 年的测评则提到晚高峰丢包率会升高。不同时间的口径有差异，实际体验以自己测试为准。

**流量口径要看清。** Storage 大盘机的流量按进出合计计算（比如 1T 是上传加下载加起来），比 Premium KVM 的单向 750GB 计法更容易用完。更麻烦的是加购价格：亚太机房的流量加购是 $15/TB/月，美国和欧洲机房只要 $3/TB/月，差了 5 倍。如果拿大盘机做频繁同步的备份，额度消耗会比你预想的快，超购也贵。

**同类价位里流量额度差很多。** 同样是 $25/年，GreenCloud 自家美欧机房的 0.5TB 存储套餐给 3TB 流量，亚太机房只有 1TB；英国的 Budget KVM 也比日本同价档流量大（3TB vs 750GB）。这个差距合理——日本优化线路的带宽成本本来就高，但如果你其实不挑线路，别只盯着日本。

**大盘机是 SATA 不是 NVMe。** Storage KVM 系列的数据盘是企业级 SATA RAID-10，适合备份、媒体库、文件服务器这类低 IOPS 场景；想要 NVMe 的高随机读写，得看 KVM 系列。
